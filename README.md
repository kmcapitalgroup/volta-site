# Site de Volta

Le site public de Volta, l'app des clubs de sport amateur. Du HTML et du CSS,
sans étape de build : ouvrir `index.html` dans un navigateur pour l'aperçu.

Publié sur GitHub Pages par `.github/workflows/pages.yml` à chaque push sur
`main`. Les images de `img/` sont des captures de l'app réduites en WebP
(560 px de large pour les téléphones, 1400 px pour la tablette).
