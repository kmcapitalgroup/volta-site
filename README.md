# Site de Volta

Le site public de Volta, l'app des clubs de sport amateur. Du HTML et du CSS,
sans étape de build : ouvrir `index.html` dans un navigateur pour l'aperçu.

Publié sur GitHub Pages directement depuis la branche `main` (Settings > Pages >
Deploy from a branch > main, / (root)) : chaque push met le site à jour. Les images de `img/` sont des captures de l'app réduites en WebP
(560 px de large pour les téléphones, 1400 px pour la tablette).
